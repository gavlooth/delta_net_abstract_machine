# delta_net_abstract_machine

A minimal C3 executable project. It uses C3 0.8.3.

## Run

```sh
c3c run
```

The executable is written to `build/delta_net_abstract_machine`.

## Layout

- `src/main.c3` — program entry point.
- `test/` — C3 test sources.
- `lib/` — project-local C3 libraries.
- `resources/` — runtime assets.
- `project.json` — compiler build configuration.
