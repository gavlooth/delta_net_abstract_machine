## Problem

`parsed.root` is an `mpc::AstNode*`, but it is:

- Owned by `ParseResult`.
- Invalid after `parsed.deinit()`.
- Full of parser nodes such as `sequence`, `many`, and `string`.

Do not connect MPC nodes directly to `Net`. Lower them into a project-owned lambda term first.

## Accessing MPC nodes

```c3
AstNode* root = parsed.root;

io::printfn("tag=%s text=%s", root.tag, root.text);

foreach (child : root.children)
{
    io::printfn("child tag=%s text=%s", child.tag, child.text);
}

AstNode* first = root.child(0);       // null when out of range
AstNode* ident = root.find("ident"); // recursive first match
```

Available fields and methods:

```c3
node.tag
node.text
node.span
node.children

node.child_count()
node.is_leaf()
node.child(index)
node.find("tag")
```

Important ownership rule:

```c3
defer parsed.deinit();
```

After that executes, `root`, its children, their tags, and their text are invalid. Copy names needed by your own AST.

Avoid using `find("abstraction")` to classify arbitrary terms: it searches recursively and could find an abstraction nested inside an application.

## Lower MPC AST into a semantic AST

Use this representation:

```text
Term :=
    BoundVar(index)
  | FreeVar(name)
  | Abstraction(body)
  | Application(function, argument)
```

Maintain a binder-name stack while lowering identifiers:

```text
λx.x       → Abstraction(BoundVar(0))
λx.λy.x    → Abstraction(Abstraction(BoundVar(1)))
λx.λx.x    → Abstraction(Abstraction(BoundVar(0)))
```

Map the grammar as follows:

- `term`: unwrap the nearest `abstraction` or `application`.
- `abstraction`: get its binder `ident`, push it, lower its body `term`, then pop it.
- `application`: collect only its top-level `atom` nodes and fold left.
- `atom`: unwrap `ident`, parenthesized `term`, or `abstraction`.
- `ident`: search the binder stack from innermost to outermost; otherwise create `FreeVar`.

For applications:

```text
f x y
```

must become:

```text
Application(
    Application(f, x),
    y
)
```

Do not use `find_all_ast(application, "atom")`: it also returns atoms nested inside parentheses and abstraction bodies. Instead, collect an `atom` and stop descending through that node:

```c3
fn void collect_atom_frontier(AstNode* node, List{AstNode*}* atoms)
{
    foreach (child : node.children)
    {
        if (child.tag == "atom")
        {
            atoms.push(child);
            continue;
        }
        collect_atom_frontier(child, atoms);
    }
}
```

## Connect the semantic AST to the net

Put this in a separate `translate.c3`, preferably in module:

```c3
module delta_net_abstract_machine;
```

Use a destination-driven encoder:

```text
emit(term, destination_child_port, level, binder_environment)
```

Every term destination is a `CHILD` port.

### Required polarity correction

`net_operations.c3:new_interface()` currently creates:

```c3
ROOT          → PARENT
FREE_VARIABLE → CHILD
```

That cannot connect to the existing fan encoding because `connect()` requires opposite polarities.

The consistent interface polarities are:

```c3
ROOT          → CHILD
FREE_VARIABLE → PARENT
```

Fix and test this before implementing translation.

### Abstraction

For `Abstraction(body)` at level `l`:

```c3
StableId node_id = new_fan(net, PARENT);
Fan fan = net.nodes.get(node_id).agent.fan;

connect(net, destination, fan.principal);
emit(body, fan.left, l, environment);
```

Port meanings:

```text
fan.principal : PARENT — abstraction result
fan.left      : CHILD  — body
fan.right     : PARENT — binder
```

Push a binder frame before emitting the body. Bound-variable occurrences should record:

```text
(destination_port, occurrence_level)
```

After emitting the body, finalize `fan.right`:

```text
0 occurrences:
    connect binder to eraser principal

1 occurrence with delta 0:
    connect binder directly to occurrence

otherwise:
    create CHILD-principal UNPAIRED replicator
    replicator level = l + 1
    delta[i] = occurrence_level[i] - (l + 1)
    connect binder to replicator principal
    connect each replicator auxiliary to its occurrence
```

Identity `λx.x` intentionally has delta `-1`:

```text
occurrence level = 0
replicator level = 1
delta = 0 - 1 = -1
```

### Application

For `Application(function, argument)` at level `l`:

```c3
StableId node_id = new_fan(net, CHILD);
Fan fan = net.nodes.get(node_id).agent.fan;

connect(net, destination, fan.left);
emit(function, fan.principal, l, environment);
emit(argument, fan.right, l + 1, environment);
```

Port meanings:

```text
fan.left      : PARENT — application result
fan.principal : CHILD  — function
fan.right     : CHILD  — argument
```

### Variables

Bound variable:

```text
Find binder by De Bruijn index.
Append (destination, level) to that binder’s occurrence list.
Do not connect it immediately.
```

Free variable:

```text
Create or reuse InterfacePort(FREE_VARIABLE, name).
Connect its PARENT port to the variable destination CHILD port.
```

The outermost call is:

```text
root interface: CHILD
emit(term, root.port, 0, empty_environment)
```
